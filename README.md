# Хоёр ертөнц (Alive my sister)

Limbo маягийн үггүй, хоёр хүний co-op тоглоом. Ах амьд ертөнцөд, нас барсан дүү нь үхэгсдийн ертөнцөд байна. Тоглогч бүр зөвхөн өөрийн ертөнцийг хардаг тул ярилцаж байж даалгавраа биелүүлнэ. Нэг нь хараад хэлж, нөгөө нь хийнэ (Operation: Tango маягаар).

## Тоглох
- **Ганцаараа:** `index.html`-ийг нээгээд «Ганцаараа тоглох» дарна. ⇅ товч (эсвэл Q) дүр сольж, дэлгэцийг нөгөө ертөнц рүү шилжүүлнэ.
- **Онлайн (2 утас):** «Онлайн тоглох» → нэг нь өрөө үүсгэнэ, нөгөө нь кодоор нь орно. Ах/Дүү сонгоод бүлгээ эхлүүлнэ. Утсаар эсвэл Discord-оор ярилцаж тоглоно.
- Утсыг хэвтээ байдлаар барина.

Удирдлага: ← → алхах · ↑/Space үсрэх · E татах, дуудах, оньсого нээх · Q/Tab дүр солих (ганцаараа) · Esc түр зогсоох.

## Бүтэц
- `js/game.js` — engine (физик, объект, дайсан, онлайн синк, оньсогын цонх)
- `js/levels/` — бүлгүүдийн өгөгдөл
- `js/enemies.js`, `js/art-enemies.js` — дайсны AI ба зураг
- `js/puzzles.js`, `js/puzzles-b.js` — оньсого мини тоглоомууд
- `js/net.js`, `js/config.js` — онлайн холболт (Supabase Realtime). Өөр Supabase project руу шилжихэд `js/config.js` доторх 2 мөрийг солино.
- `js/ui.js` — цэс, lobby, бүлгийн дэлгэц
- `docs/` — багийн гэрээ (ARCHITECTURE*.md), түүх, бүлгийн дизайн, баг
- `tests/` — автомат тест (Python Playwright)
