# Оньсого B — шагай, өнгөт чулуу, хоёр хагас

Файлууд: `js/puzzles-b.js`, `css/puzzles-b.css`, `puzzles-b-preview.html`, тест `tests/puzzles-b/test_puzzles_b.py`.
`index.html`-д `js/puzzles.js` (A дизайнер)-ийн **дараа** ачаална: `<script src="js/puzzles-b.js">`, `<link rel="stylesheet" href="css/puzzles-b.css">`.
Бүгд «Operation: Tango» загвар: нэг нь зөвхөн өөрийн дэлгэцэн дээр харж **хэлнэ**, нөгөө нь **хийнэ**. Буруу хариулт = engine чанга дуу гаргаж дайсныг сэрээнэ.

## 1. Шагай (`shagai`)

```js
{ id:'PZ1', type:'puzzle', world:0, x:1500, kind:'shagai', target:'G2', params:{} }
{ id:'CL1', type:'clue',   world:1, x:1520, puzzle:'PZ1' }
```

| | Юу харна | Юу хийнэ / хэлнэ |
|---|---|---|
| **Сэжүүртэй тоглогч** (нөгөө ертөнц) | Газар дээр дөрвөн шагай (тугтай гадас хажууд нь). ◎ дарахад том харагдана: 1–4 дугаартай, тус бүр нэг талаараа буусан: **морь, тэмээ, хонь, ямаа**. | Зүүнээс баруун тийш хэлнэ: «Нэгдүгээр нь хонь, хоёр нь ямаа, гурав нь морь, дөрөв нь ямаа». |
| **Шийдэгч** (төхөөрөмжийн дэргэд) | Намхан чулуун дээрх эсгий, дээр нь дөрвөн шагай. ◎ → «Шагайг эргүүл». | Шагай бүрийг дарах бүрт дараагийн тал руу эргэнэ (морь → тэмээ → хонь → ямаа). Тааруулаад **Батлах**. |

Хэлбэрүүд (шошготой, гэхдээ дүрсээр ч ялгагдана): **морь** — өндөр, хавтгай оройтой, голдоо ховилтой; **тэмээ** — өндөр, хоёр бөхтэй; **хонь** — намхан, гөлгөр бөмбөгөр; **ямаа** — намхан, оройдоо ховилтой, дундаа хонхор.
Хариултын орон зай: 4⁴ = **256** (санамсаргүй таах ≈ 0.4%). Эхлэх байрлалд дээд тал нь 2 шагай аль хэдийн зөв байна (хэзээ ч шийдэгдсэн байдлаар эхлэхгүй).

## 2. Өнгөт чулуу (`riddle`, Keep Talking маягийн)

```js
{ id:'PZ2', type:'puzzle', world:1, x:2400, kind:'riddle', target:'B3', params:{} }
{ id:'CL2', type:'clue',   world:0, x:2380, puzzle:'PZ2' }
```

| | Юу харна | Юу хийнэ / хэлнэ |
|---|---|---|
| **Шийдэгч** | Сийлбэртэй баганын хажууд гурван чулуу. ◎ → зүүнээс баруун тийш 3 өнгөт чулуу (**хар, цагаан, улаан, хөх, шар**-аас, давтагдаж болно) + хоёр оронтой тоон дугуй. | Өнгийг хэлнэ: «Хар, хөх, цагаан». Найзынхаа хэлсэн тоог ▲/▼-оор тавиад **Батлах**. |
| **Сэжүүртэй тоглогч** | Дүрмийн хүснэгттэй хөшөө (оройд нь таван өнгийн цэг). ◎ → хоёр хүснэгт: «Эхний цифр», «Хоёр дахь цифр», тус бүр 4 мөр. | Найзаасаа өнгийг асууна. Хүснэгт бүрийг **дээрээс доош** уншиж, **эхний таарсан мөрийн** цифрийг авна: «Эхний цифр 6, хоёр дахь нь 0 — жаран». |

Дүрмийн жишээ: «Хэрэв улаан чулуу яг хоёр байвал → 7», «Хэрэв хар чулуу огт байхгүй бол → 3», «Хэрэв зүүн талын чулуу шар бол → 5», «Хэрэв гурван чулуу бүгд өөр өнгөтэй бол → 1», «Хэрэв хоёр захын чулуу ижил өнгөтэй бол», «Хэрэв цагаан чулуу хөх чулуунаас олон байвал», сүүлийн мөр үргэлж «Бусад бүх үед». Дүрэм, цифр, чулуу seed бүрт өөр (3000 seed-ээс 3000 өөр хүснэгт); 4 мөр бүгд байнга таардаг (зөвхөн «Бусад» биш).
Хариултын орон зай: 00–99 = **100** (таах 1%). Сэжүүр чулууг харуулдаггүй, шийдэгч дүрмийг хардаггүй — ярихгүйгээр шийдэх аргагүй.

## 3. Хоёр хагас (`split`, хоёр талын код)

Хоёр ертөнцөд тус бүр нэг **хагарсан хөшөө** (төхөөрөмж ба сэжүүр нэг дор), clue объект хэрэггүй:

```js
{ id:'SP1', type:'puzzle', world:0, x:3000, kind:'split', target:'G4', params:{pair:'P1', side:0} }
{ id:'SP2', type:'puzzle', world:1, x:3000, kind:'split', target:'GB4', params:{pair:'P1', side:1} }
```

Код = 4 тэмдэг (8-аас, давтагдаж болно): **нар, сар, од, гал, ус, уул, мод, гэр**.

| | Харна («Тэмдгээ найздаа хэл») | Оруулна («Найзынхаа тэмдгийг оруул») |
|---|---|---|
| **Тал 0** | 3, 4-р тэмдэг | 1, 2-р тэмдэг (тал 1-ийн хөшөөн дээр бий) |
| **Тал 1** | 1, 2-р тэмдэг | 3, 4-р тэмдэг (тал 0-ийн хөшөөн дээр бий) |

Хоёулаа **хэлж**, хоёулаа **оруулна**: «Миний гурав нь уул, дөрөв нь од». — «Миний нэг нь нар, хоёр нь гал». Оруулсан нүдийг дарвал арилна, **Арилгах** хоёуланг нь цэвэрлэнэ, **Батлах** хоёр нүд дүүрсэн үед л идэвхждэг. Тал бүр өөрийн target-аа асаана.
Хариултын орон зай: тал бүрт 8² = **64** (таах ≈ 1.6%), харсан тэмдэг нь өөрийн хариултын талаар юу ч хэлэхгүй.
Хөшөөний ан цав хамтрагчийн өнгөөр гэрэлтэнэ: амьд ертөнцөд улаан (дүүгийнх), үхэгсдийн ертөнцөд хөх (ахынх); шийдэгдэхэд цагаан гэрэл болно.

**Engine-д (Lead):** хоёр тал ижил кодтой байхын тулд `rand`-ийг session seed + `params.pair`-аас үүсгэнэ. Модуль `TW.puzzles.split.seedKey(o)` (= `o.params.pair`) өгдөг — бусад төрөлд `o.id`. `gen(rand, params)` нь `params.side`-ийг уншина.

## Бүгдэд нийтлэг
- Ганцаараа (solo): шийдэгч сэжүүр рүү алхаж (⇅) уншаад буцаж шийднэ; split-д хоёр хөшөөг ээлжлэн нээнэ (харах хэсэг нь шийдэх цонхонд байгаа).
- `solve` / `showClue` цэвэрлэх функц буцаана; `api.success()` / `api.fail()` Батлах дарахад **яг нэг удаа** дуудагдана, дараа нь бүх товч идэвхгүй болно.
- 844×390 (body ≈ 780×290)-д гүйлгэхгүй багтана, 640×320 хүртэл шалгасан; бүх товч ≥ 44 px; `--twpz-*` хувьсагчийг дагана.
- Тоглоомын дотор: шагай — тугтай гадас, эсгийтэй намхан чулуу; өнгөт чулуу — гурван бөөрөнхий чулуу ба хоёр цагирагтай багана, сэжүүр нь дүрмийн хөшөө; хоёр хагас — ан цавтай хөшөө. Бүгд хоёр палитрт (амьд: хар дүрс; үхэгсэд: цайвар чулуу) ажиллана.
