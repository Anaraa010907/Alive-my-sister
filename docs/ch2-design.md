# 2-р бүлэг «Чонын хөндий» — түвшний дизайн

Файл: `js/levels/ch2.js`. Сэдэв: **НУУГД, УРХАЙД, ЯРЬ.** Нэг нь харж хэлнэ, нөгөө нь хийнэ (Operation: Tango).
Урт 4100, эхлэл x 100 (хоёулаа), гарц `exit:{x:3950, kind:'pass'}` (хоёулаа ±45 дотор газар дээр зогсоход дуусна). `ambience:'valley'`.
Ах = 0-р ертөнц (амьд), Дүү = 1-р ертөнц (үхэгсдийн). Бүх x нь **дүрийн зүүн ирмэг** (`c.x`); «төв» гэвэл `x + w/2` (ах w 14, дүү w 12).

## Хэрэглэсэн тоо (engine/AI-аас)
- Чоно урд 160 / ар 50 хардаг, хөлийн өндрийн зөрүү < 40 үед л харна → **42 өндөр хадан дээрх ахыг харахгүй**. ≤ 22.5 л үсэрнэ, ангал давахгүй.
- Шулам ≤ 24.5 л авирна → **26+ өндөр чулуу нь түүнд хана**. Ахын дуудлагын цуурай r 260, ясан алхаа r 170, дүүгийн буулт r 110 зөвхөн ≈39-өөс өндрөөс унахад. Дүү шуламаас ≥ 16 дээр зогсвол хэзээ ч цохихгүй.
- Хэрээ нүүрээрээ 190 хардаг, ≈3.3 сек тутам эргэнэ; дохио өгөхөд 600 доторх чоно 4 сек хөөнө.

## A. Хөндийн ам (0–720) — нуугдаж сурах
- **Ах харна:** W1 чоно 380↔590 эргэлдэнэ (зогсоол бүрт 1 сек). **Дүү:** ясан шал 330–390 дээр алхахад дуу гарна — ойр шулам байхгүй, зүгээр сургалт. Эхэнд цасанд эсгий гутал (`decor 'boot'` x 200, engine зурж эхлэхээр).
- **Хэлэх:** энд ах ганцаараа; ах «чоно ирж байна, хүлээ» гэж дүүд хэлж болно. Дүү ≈950 хүртэл алхаад зогсоно.
1. Ах x 180 хүртэл яв (чоно зүүн захдаа 220 хүртэл хардаг — 180 аюулгүй).
2. Чоно **баруун тийш харж**, төв нь ≥ 470 болтол хүлээ.
3. Ах x 473 (өвсний төв 480) хүртэл алхаад **зогс** → 0.25 сек дараа нуугдана.
4. Чоно 590-д эргэж ирээд ахын дээгүүр өнгөрнө. Чоно **зүүн тийш харж**, төв нь < 425 болмогц (ахаас 50+ ард) ах баруун тийш гүй, 640-д үсэр (ангал 40), x 720.
- Чоно эргэхэд ах 700+-д, ангалын цаана → чоно ангал давахгүй.

## B. Шуламын тавцан (720–1400) — урхидах
- **Дүү харна:** S1 шулам 30 өндөр тавцан (1040–1300) дээр 1130–1250 хооронд мөлхөнө. Тавцангийн баруун захын доор нүх 1300–1350, цаана нь 36 өндөр хана.
- **Ах:** юу ч харахгүй. Замдаа RV1 хэрээ (900) ахыг харвал дуугарч, W1 ангалын захад ирээд улина — аюулгүй, «хэрээ чоныг дууддаг» гэдгийг заана.
- **Дүү хэлэх:** «Ах аа, хадны цаана гар, яг 1300-гаас цааш — тэндээс дууд». Ахын цуурайг дүү өөрийн дэлгэц дээр хөх цагиргаар харна: «хэт зүүн байна», «боллоо».
1. Ах x 1353 (төв 1360) хүртэл яв, **◎ дар**. Цуурай 1360-д → S1 сонсож баруун тийш мөлхөж, тавцангаас нүх рүү унаад хананд тулж, буцаж авирч чадахгүй **үүрд хоригдоно** (≈4.5 сек).
   - Зөв бүс: ахын төв 1310–1385 (S1 хаана ч байсан сонсоно). 1040–1300-аас дуудвал S1 тавцан дээрээ үлдэнэ. **< 1040-аас бүү дууд**: S1 зүүн тийш буугаад дүүгийн зам дээр гацна.
2. (Solo: ⇅) Дүү 950-аас: 1040-д үсэрч тавцан дээр гар (буулт чимээгүй), баруун зах хүртэл алх, **1300-д үсэрч** нүхийг давж хананы орой дээр буу, баруун талаар нь алхаж бууна (36 → чимээгүй), x 1494 (төв 1500) — PZ1.
- Хана дээр буухад гарсан дуунаар S1 доор нь хашгирч болох ч хүрч чадахгүй. Дүүгийн шалгах цэг 1400.

## C. Тамгат хад (1400–1600) — symbols
- **Ах уншина:** CL1 (x 1470) — сийлбэртэй хадан дээрх 4 тамгыг дүүд хэлбэрээр нь дүрсэлнэ. **Дүү тайлна:** PZ1 (x 1500), зөв бол **ахын** хаалга G1 (1560) нээгдэнэ.
- Аюулгүй: ахын ертөнцөд энд дайсан алга; дүүгийн буруу хариулт (r 320) S1-ийг сэрээсэн ч тэр нүхэндээ.
1. Ах x 1463 (төв 1470) → ◎ → clue. 2. Дүү x 1494 → ◎ → тайлна. 3. G1 нээгдэх (1.4 сек).

## D. Сүүдэр чоно (1600–2250) — нууц аюул `seenBy:'other'`
- **SW1** ахыг алж чадна, гэхдээ **зөвхөн дүүгийн дэлгэц дээр** сүүдэр болж харагдана. Ах сохор.
- **Дүү хэлэх:** «Хадан дээрээ хүлээ… одоо чоно баруун тийш явж байна — буу, өвс рүү гүй!… нуугд, бүү хөдөл… дээгүүр чинь өнгөрлөө… одоо гүй, ангал дээгүүр үсэр!» Дүү ямар ч аюулгүй (энэ хэсэгт шулам алга), ахтай зэрэгцэн алхаж харна.
1. Ах G1-ийг өнгөрч, 1650-д үсэрч харуулын хад (1660–1702, 42 өндөр) дээр x 1675-д зогс — чоно харахгүй.
2. SW1 **баруун тийш харж**, төв нь ≥ 1930 болтол хүлээ.
3. Ах хаднаас бууж x 1950 (өвсний төв 1957) хүртэл алх, зогс → нуугдана. SW1 2110-д эргэж ирээд дээгүүр нь өнгөрнө.
4. SW1 **зүүн тийш харж**, төв нь < 1905 болмогц ах гүй, 2210-д үсэр, x 2293 хүртэл.

## E. Харанхуй агуй (2250–2740) — maze + харанхуй бүс
- **Төөрдөг:** ах PZ2 (2300) дээр 4 удаа 3 хаалганы аль нэгийг сонгоно; **дүү** CL2 (2300)-д агуйн зургийг дээрээс нь харж «зүүн, дунд, баруун, зүүн» гэж хэлнэ. Зөв бол G2 (2340) нээгдэнэ.
- **Харанхуй 2360–2740:** ахын дэлгэц хар, зөвхөн өөрийн эргэн тойрон. Дүүгийн дэлгэц дээр ghost map: 3 ангал, 1 хад. Дүү x ≈ 2544 (төв 2550)-д **хөдөлгөөнгүй** зогсоод хөтөлнө (энд шулам алга — аюулгүй).
- **Дүү хэлэх (жишээ):** «Шулуун… зогс! Урд чинь нүх — одоо үсэр. … Урд чинь өндөр хад, үсэрч гар. Хадны захаас үсэр — доор нь нүх! Буусан даруйдаа дахиад нүх — үсэр!»
1. Дүү x 2294 → ◎ → CL2 уншина; ах x 2293 → ◎ → PZ2 тайлна; G2 нээгдэнэ (1.4 сек).
2. Дүү x 2544-д очиж зогсоно.
3. Ах баруун тийш: **2410-д үсэр** (ангал 2410–2450) → **≈2488-д үсэр** (хад 2500–2580, 40 өндөр) → хадны орой дээрээс **2580-д үсэр** (ангал 2580–2620) → газар 2620–2680 → **2680-д үсэр** (ангал 2680–2720) → x 2735.

## F. Хоёр цоож (2740–3000) — split
- Ах PZ3A (2880, side 0), дүү PZ3B (2880, side 1), `pair:'SP1'`. Төхөөрөмж бүр кодын хагасыг харуулж, нөгөө хагасыг оруулахыг шаардана → **мэдээлэл хоёр тийш**. PZ3A нь **дүүгийн** G3B-г, PZ3B нь **ахын** G3A-г (2940) нээнэ.
- Хоёулаа аюулгүй (ойр дайсан алга).
1. Ах x 2873, дүү x 2874; тус бүр ◎ → харсан цифрээ хэлж, нөгөөгийнхийг оруулна. 2. Хоёр хаалга нээгдэнэ.

## G. Модон саравч (3000–3500) — доогуур нь урхидах
- **Дүү харна:** гишгүүр чулуу 3150–3180 (26 — шуламд хана), унасан мод 3180–3370 (орой G-50, доод тал G-38 → шулам **доогуур нь** мөлхөнө). S2 3320–3440 хооронд, модны баруун захын доор, дүүгийн буух газар дээр.
- **Ах:** x ≈3200-д W2 харахгүй (W2 зүүн захдаа 3240 хүртэл хардаг).
- **Дүү хэлэх:** «Би модон дээр гарлаа. Ах аа, 3200 орчим очоод дууд… шулам доогуур минь зүүн тийш явлаа… одоо буулаа!»
1. Дүү 3150-д үсэрч (шууд модон дээр эсвэл чулуугаар) модон дээр гар, баруун зах x 3355-д зогс — аюулгүй (S2-оос 50 дээр).
2. Ах x 3193 (төв 3200) → **◎**. Цуурай → S2 модны доогуур зүүн тийш мөлхөж, гишгүүр чулуунд тулж (төв ≈3195) 2 сек хайгаад, 35 u/s-ээр удаан буцна.
   - Зөв бүс: ахын төв 3181–3260 (S2 хаана ч байсан сонсоно, буух газраас хангалттай хол татна).
3. S2-ийн төв **< 3240** болмогц (hunt/search/return) дүү модны баруун захаас унаж (50 → r 110 дуу, S2 130+ хол — сонсохгүй) баруун тийш алхаж x 3520 хүртэл. Цонх ≈ 3–4 сек.

## H. Чонын сүрэг (3400–4020) — төгсгөл: хөөцөлдөөн → хад → хэнгэрэг
- **Ах харна:** W2 3400↔3580, өвс 3450–3500, хэрээний хад 3700–3742 (42) — RV2 хэрээ оройд нь (зүүн тийш харж эхэлнэ; үүрэнд нь дүүгийн улаан тууз, story.md). Хадны цаана халаас 3742–3830 (CL4 3790, хаалга G4 3830). **Хад чонод хана** → халаас бүрэн аюулгүй.
- **Дүү харна:** чулуу A 3610–3670, нүх 3670–3720 дотор хуучин шулам S3 (гарч чадахгүй), чулуу B 3720–3760, хэнгэрэг PZ4 3790.
1. Ах x 3193-аас: W2 **баруун тийш харж**, төв ≥ 3430 болтол хүлээ → x 3468 (өвсний төв 3475) хүртэл алх, зогс → нуугдана.
2. W2 эргэж ирээд дээгүүр нь өнгөрнө. W2 **зүүн тийш харж**, төв < 3422 болмогц ах баруун тийш **гүй**.
3. RV2 зүүн тийш харж байвал (x ≥ ≈3530) **дуугарна** → W2 хөөнө (135 vs 120). Ах ≈100 зайтай хад хүрнэ: **3690-д үсэрч** хадан дээр гар → цаашаа халаас руу бууж x 3783 (төв 3790). W2 хадны хананд тулж **улина** (howl) → буцна. RV2 нөгөө тийш харж байсан бол хөөцөлдөөн хожуу (ах хад дээр/халаасанд байхад) болно — аль ч тохиолдолд аюулгүй.
4. Ах CL4-д ◎ → хэнгэргийн хэмнэлийг (урт/богино) дүүд хэлнэ. Аюулгүй.
5. Дүү x 3500-аас: **3610-д үсэрч** чулуу A-д (чимээгүй), **3670-д үсэрч** нүхийг (50) давж чулуу B-д (буухад S3 доор хашгирна — хүрэхгүй), B-ээс бууж x 3783 → ◎ → PZ4. Буруу бол дуу (r 320) S3-ыг сэрээнэ, гэхдээ тэр нүхэндээ. Зөв бол G4 нээгдэж, овоо гэрэлтэнэ.
6. Ах x 3943, дүү x 3944 → гарц (3950) → 'ending' → 'done'.
- **Дүүгийн хэлэх:** «Ах аа, хад дээр гарсан уу? Хэнгэргийн хэмнэлийг хэл… Миний доор шулам байна, гэхдээ гарч чадахгүй.» Story-ийн «Намжсан улиан» агшинд (чоно улих үед дүү ◎) зориулсан газар энэ.
