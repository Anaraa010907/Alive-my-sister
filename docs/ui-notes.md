# UI flow v2 (js/ui.js, css/ui.css; preview at ui-preview.html)
Always landscape. Every screen fits 844×390 without scrolling and scales up to 1280×720; base CSS = desktop sizes, `@media (max-height:480px)` = phone landscape.

- **Title**: three choices side by side. **Ганцаараа тоглох** → `game.startSolo(id)`. It continues the first unlocked chapter that has no best record, otherwise the last unlocked chapter, and a caption names that chapter. **Онлайн тоглох** → lobby. **Бүлгүүд** → solo chapter select. With no chapters only the solo button shows.
- **Chapter select**: cards in a row (they wrap when there are many). Locked chapters are disabled, and a red mark shows the chapter to continue. Буцах / Esc go back to where the select was opened.
- **Online lobby** (`TW.net`, resolved lazily; missing → «Онлайн горим бэлэн биш», `available()` false → the same plus a note about the preview page):
  - Menu → Өрөө үүсгэх (busy → room with a big code + «Найздаа энэ кодыг хэл») / Өрөөнд орох. Joining uses 4 big letter slots over one transparent input: auto-uppercase, Cyrillic lookalikes map to Latin, Enter / «Орох» joins, and the slots sit high on the screen so the keyboard doesn't cover them.
  - Errors: notfound «Ийм өрөө олдсонгүй» / full «Өрөө дүүрсэн байна» show inline. offline or a timeout shows «Сүлжээнд холбогдож чадсангүй» + a note that the published preview can't open connections. net.js emits `status:error` *before* create/join reject, so while one is pending only its promise reports. In the room, `status:error` (lost / full) → error view.
  - Room: the code on the left with the partner's status; role cards **Ах** (амьд ертөнц) / **Дүү** (үхэгсдийн ертөнц) with «Чи» / «Найз» badges. The host wins a conflict: the guest flips automatically with a note, and the guest can't take the host's role. The host picks a chapter (chips) and presses **Эхлэх** (enabled only when the partner is present and roles differ, with a one-line reason) → `game.startOnline(id)`. The guest sees «Найз чинь бүлгээ сонгож байна…» + the host's current pick. The tip line is always shown.
  - Presence I send: `TW.net.setInfo({role, at:'lobby'|'game', ch})` (ch = host's pick). It is reset to `{role:null, at:'lobby', ch:null}` before every create/join and after leaving, because net.js keeps the payload between rooms.
- **Playing**: pause button top-right (44px, safe-area aware). The chapter card fades in the sky (upper 70% of the canvas, pointer-events none); online it adds «Чи — Ах · амьд ертөнц» in blue, or the red Дүү line.
- **Pause**: Үргэлжлүүлэх on top, the rest in two columns: Бүлгийг дахин эхлэх / Бүлгүүд (solo) / **Бүлэг солих** (online host: sends `{t:'menu'}`, both screens go to the room) / Дуу / **Өрөөнөөс гарах** (online: `game.leaveOnline()` → title).
- **Chapter end** (paper): solo → Дараагийн бүлэг / Дахин тоглох / Бүлгүүд. Online host → Дараагийн бүлэг (`startOnline(next)`) / Дахин тоглох / Бүлэг солих / Өрөөнөөс гарах. Online guest → «Найз чинь дараагийн бүлгийг эхлүүлнэ…» + Өрөөнөөс гарах; the next game starts on `onlineStart`.
- **Partner left** (`peer {present:false}` while `game.mode()==='online'`): overlay «Найз чинь гарлаа» that pauses the game → Хүлээх (waiting dots + code) / Цэс (`leaveOnline` → title). A mid-game `status:error` shows the same overlay titled «Сүлжээнд холбогдож чадсангүй». When the partner returns: if their info says `at:'game'` (a network blip), the overlay hides and the game resumes, but only if the UI paused it. Otherwise (they re-joined through the lobby) both go to the room to restart together. `peerMenu` → room.
- **Rotate overlay**: a touch device in portrait → «Утсаа хэвтээ эргүүлнэ үү» + an animated SVG phone, z-index above everything. While it shows it calls `game.pause(true)` and resumes only if it paused the game; keys are swallowed.
- **Fullscreen**: solo start, chapter play, room create/join and Эхлэх call `requestFullscreen()` then `screen.orientation.lock('landscape')` inside the click handler, with failures caught. This happens on touch devices only; desktop browsers are never put into fullscreen.
- Every start runs synchronously in the click/key handler (audio unlock). With a menu open, arrows/Tab move focus, Enter/Space press buttons, and those keys never reach the engine; Esc goes back one level. Every `game.*` and `TW.net.*` call is guarded. `prefers-reduced-motion` turns animations off.
- Tests: screenshots are in tests/ui/v2/ (p* phone 844×390, r* portrait 390×844, d* 1280×720, game-* real index.html, i* two tabs of the real engine + net.js with `?net=local`).
