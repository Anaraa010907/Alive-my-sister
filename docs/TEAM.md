# Хоёр ертөнц — AI хөгжүүлэлтийн баг

Баг бүр зөвхөн өөрийн файлууд дээр ажиллана (docs/ARCHITECTURE.md → "Files and owners"). Продюсер ажлыг хуваарилж, нэгтгэж, шалгана.

| Дүр | Хариуцлага | Файлууд |
|---|---|---|
| Продюсер / ахлах хөгжүүлэгч | Ажил хуваарилах, engine, нэгтгэл, нийтлэх | index.html, js/tw.js, js/game.js, js/levels/ch1.js |
| Түвшин, даалгаврын дизайнер | Бүлгийн зураглал, оньсого, шалгах цэг, hint | js/levels/chN.js, docs/chN-design.md |
| Дүр, дайсан бүтээгч | Дайсан, орчны зураг ба хөдөлгөөн | js/art-enemies.js, art-preview.html |
| Дайсны AI программист | Дайсны төлөв, харах/сонсох/хөөх | js/enemies.js |
| Дуу, хөгжмийн дизайнер | Процедурал дуу, хөгжмийн давхарга | js/audio-ext.js, audio-preview.html |
| UI/UX дизайнер | Нүүр, бүлэг сонгох, түр зогсоох, бүлгийн дэлгэц | js/ui.js, css/ui.css, ui-preview.html |
| Түүх, ертөнцийн зохиолч | Үггүй түүх, бүлгийн утга, endText | docs/story.md |
| QA шалгагч | Автомат playthrough, алдааны тайлан | tests/ |

Дараа нэмэх: Сүлжээний инженер (онлайн co-op: Supabase + LiveKit), Godot руу шилжүүлэгч, Маркетинг (Steam хуудас, trailer), Орчуулагч (англи).

Шинэ бүлэг нэмэх дараалал: зохиолч + дизайнер (бүлгийн санаа, зураглал) → зураач + AI + дуу (шинэ дайсан, механик) → продюсер (engine-д шинэ объект хэрэгтэй бол) → QA → нийтлэх.
